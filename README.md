# Multimex AM - Coming Soon Website

Official "Coming Soon" landing page for **multimex-am.cz** with bilingual support (Czech & English) and animated UI.

## Features
- Interactive Czech / English language switcher
- Animated Typewriter subtitle
- Responsive glassmorphism logistics cards
- Glow effects & modern dark design

## Deployment & Setup

1. **Extract ZIP File**: Unpack the archive to get `index.html`.
2. **Push to GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for multimex-am coming soon page"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   git push -u origin main
   ```
3. **GitHub Pages (Optional)**: Enable GitHub Pages in repository settings pointing to `main` branch root to publish immediately.
